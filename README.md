# Попелястий Шпиль

Браузерна рольова гра в дусі «Кристалу Вічності»: Землі Кабаллону, Попелясті землі й Закарпаття на одній карті. Ремесла, самоцвіти, підземелля з босами, зачистки районів, квести, максимальний рівень 10.

Вся гра в одному файлі `index.html`, без сервера. Герої та прогрес зберігаються в браузері гравця (localStorage).

## Як запустити на GitHub Pages

1. Залийте вміст цієї папки в репозиторій.
2. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)`.
3. Через хвилину гра буде за адресою `https://<ваш-нік>.github.io/<назва-репозиторію>/`.

Локально досить відкрити `index.html` у браузері.

## Як змінювати гру

Код лежить у `src/` по модулях:

| Файл | Що всередині |
|---|---|
| `01-helpers.js` | допоміжні функції, іконки |
| `02-bestiary.js` | бестіарій і малювання демонів |
| `03-world.js` | карта світу, локації, дороги, райони |
| `04-mobs.js` | моби і формули їхньої сили |
| `05-items.js` | речі, самоцвіти, крамниці, ремесла, рецепти, підземелля |
| `06-npc-quests.js` | персонажі і квести |
| `07-state.js` | стан героя, рівні, характеристики |
| `08-scenes.js` | малювання локацій і карти |
| `09-render.js` | інтерфейс, карта, локація |
| `10-battle.js` | бій |
| `11-crafts.js` | збирання, крафт, гнізда |
| `12-dungeon.js` | підземелля |
| `13-ui.js` | вікна: герой, торба, крамниці, журнал, ремесла |
| `14-main.js` | подорожі, керування, головний цикл |
| `15-login.js` | екран входу і герої |
| `style.css` | стилі |

Після змін зберіть гру заново:

```
python3 build.py
```

Скрипт склеїть `src/` в новий `index.html`.

## Про вхід

Герої зберігаються тільки в цьому браузері на цьому пристрої. Пароль лише береже від випадкового входу на спільному комп'ютері, це не онлайн-акаунт. Якщо очистити дані сайту в браузері, герої зникнуть.
